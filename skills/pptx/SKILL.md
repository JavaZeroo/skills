## 设计理念

**不要创建无聊的幻灯片。** 白色背景上的普通项目符号不会给人留下深刻印象。考虑为每张幻灯片从以下列表中选择创意。

### 开始之前

- **选择大胆的、与内容契合的配色方案**：配色方案应该感觉是为这个主题设计的。如果将您的颜色换入完全不同的演示文稿中仍然"有效"，那么您的选择还不够具体。
- **主色优于均衡**：一种颜色应该主导（视觉重量的 60-70%），配以 1-2 种辅助色调和一个鲜明的强调色。绝不给所有颜色相同的权重。
- **深色/浅色对比**：标题和结论幻灯片使用深色背景，内容幻灯片使用浅色（"三明治"结构）。或者全程使用深色以获得高端感。
- **选定一个视觉主题**：选择一个独特的元素并在整个演示文稿中重复——圆形图像框架、彩色圆圈中的图标、单边粗边框。贯穿每张幻灯片。

### 配色方案

选择与主题匹配的颜色——不要默认使用通用蓝色。以这些配色方案为灵感：

| 主题 | 主色 | 辅助色 | 强调色 |
|------|------|--------|--------|
| **午夜行政** | `1E2761`（海军蓝）| `CADCFC`（冰蓝）| `FFFFFF`（白色）|
| **森林与苔藓** | `2C5F2D`（森林绿）| `97BC62`（苔藓绿）| `F5F5F5`（奶油色）|
| **珊瑚活力** | `F96167`（珊瑚红）| `F9E795`（金色）| `2F3C7E`（海军蓝）|
| **暖赤土色** | `B85042`（赤土色）| `E7E8D1`（沙色）| `A7BEAE`（鼠尾草绿）|
| **海洋渐变** | `065A82`（深蓝）| `1C7293`（蓝绿）| `21295C`（午夜蓝）|
| **炭灰简约** | `36454F`（炭灰）| `F2F2F2`（米白）| `212121`（黑色）|
| **蓝绿信任** | `028090`（蓝绿）| `00A896`（海泡沫）| `02C39A`（薄荷绿）|
| **浆果与奶油** | `6D2E46`（浆果色）| `A26769`（尘玫瑰）| `ECE2D0`（奶油色）|
| **鼠尾草宁静** | `84B59F`（鼠尾草绿）| `69A297`（桉树绿）| `50808E`（石板灰）|
| **樱桃大胆** | `990011`（樱桃红）| `FCF6F5`（米白）| `2F3C7E`（海军蓝）|

### 每张幻灯片

**每张幻灯片都需要一个视觉元素**——图像、图表、图标或形状。纯文字幻灯片令人难忘不了。

**布局选项：**
- 两列（左文字，右插图）
- 图标 + 文字行（彩色圆圈中的图标，粗体标题，下方描述）
- 2x2 或 2x3 网格（一侧图像，另一侧内容块网格）
- 半出血图像（完整左侧或右侧）配内容叠加

**数据展示：**
- 大型统计数据标注（60-72pt 大数字，下方小标签）
- 比较列（前后对比、优缺点、并排选项）
- 时间线或流程图（编号步骤、箭头）

**视觉精致：**
- 章节标题旁的小彩色圆圈中的图标
- 关键统计数据或标语的斜体强调文字

### 字体排版

**选择有趣的字体组合**——不要默认使用 Arial。选择有个性的标题字体并搭配干净的正文字体。

| 标题字体 | 正文字体 |
|---------|---------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| Impact | Arial |
| Palatino | Garamond |
| Consolas | Calibri |

| 元素 | 尺寸 |
|------|------|
| 幻灯片标题 | 36-44pt 粗体 |
| 章节标题 | 20-24pt 粗体 |
| 正文 | 14-16pt |
| 说明文字 | 10-12pt 淡化 |

### 间距

- 最少 0.5" 边距
- 内容块之间 0.3-0.5"
- 留有呼吸空间——不要填满每一寸

### 避免（常见错误）

- **不要重复相同的布局**——在幻灯片间变换列、卡片和标注
- **不要居中正文**——段落和列表左对齐；只有标题居中
- **不要吝啬尺寸对比**——标题需要 36pt+ 才能从 14-16pt 正文中突出
- **不要默认使用蓝色**——选择反映特定主题的颜色
- **不要随意混合间距**——选择 0.3" 或 0.5" 间隙并保持一致
- **不要只设计一张幻灯片而其余保持简单**——要么全部投入，要么全程保持简单
- **不要创建纯文字幻灯片**——添加图像、图标、图表或视觉元素；避免纯标题 + 项目符号
- **不要忘记文字框内边距**——将线条或形状与文字边缘对齐时，设置文字框 `margin: 0` 或偏移形状以考虑内边距
- **不要使用低对比度元素**——图标和文字都需要与背景有强对比；避免浅色背景上的浅色文字或深色背景上的深色文字
- **绝不在标题下使用装饰线**——这是 AI 生成幻灯片的标志；改用空白或背景色

## 质量保证（必需）

**假设存在问题。您的工作是找到它们。**

您的第一次渲染几乎从不正确。以找 bug 的心态而非确认步骤来处理质量保证。如果第一次检查时没有发现任何问题，那您看得还不够仔细。

### 内容质量保证

```bash
python -m markitdown output.pptx
```

检查缺失内容、拼写错误、错误顺序。

**使用模板时，检查遗留的占位符文字：**

```bash
python -m markitdown output.pptx | grep -iE "xxxx|lorem|ipsum|this.*(page|slide).*layout"
```

如果 grep 返回结果，在声明成功之前修复它们。

### 视觉质量保证

**⚠️ 使用子代理**——即使只有 2-3 张幻灯片。您一直在盯着代码，会看到您期望的内容，而不是实际存在的内容。子代理有新鲜的眼光。

将幻灯片转换为图像（见[转换为图像](#转换为图像)），然后使用此提示：

```
视觉检查这些幻灯片。假设存在问题——找到它们。

寻找：
- 重叠元素（文字穿过形状、线条穿过文字、堆叠元素）
- 文字溢出或在边缘/框边界处被截断
- 为单行文字定位的装饰线但标题换行到两行
- 来源引用或页脚与上方内容碰撞
- 元素太近（< 0.3" 间隙）或卡片/章节几乎相触
- 不均匀间隙（一处有大空白区域，另一处拥挤）
- 距幻灯片边缘的边距不足（< 0.5"）
- 列或类似元素对齐不一致
- 低对比度文字（例如奶油色背景上的浅灰色文字）
- 低对比度图标（例如深色背景上没有对比圆圈的深色图标）
- 文字框太窄导致过多换行
- 遗留的占位符内容

对于每张幻灯片，列出发现的问题或关注点，即使是次要问题。

读取并分析这些图像：
1. /path/to/slide-01.jpg（预期：[简短描述]）
2. /path/to/slide-02.jpg（预期：[简短描述]）

报告发现的所有问题，包括次要问题。
```

### 验证循环

1. 生成幻灯片 → 转换为图像 → 检查
2. **列出发现的问题**（如果未发现任何问题，再更批判地看一次）
3. 修复问题
4. **重新验证受影响的幻灯片**——一个修复往往会创造另一个问题
5. 重复直到一次完整检查没有新问题

**在完成至少一次修复和验证循环之前，不要宣告成功。**

## 转换为图像

将演示文稿转换为单张幻灯片图像进行视觉检查：

```bash
python scripts/office/soffice.py --headless --convert-to pdf output.pptx
pdftoppm -jpeg -r 150 output.pdf slide
```

这会创建 `slide-01.jpg`、`slide-02.jpg` 等文件。

修复后重新渲染特定幻灯片：

```bash
pdftoppm -jpeg -r 150 -f N -l N output.pdf slide-fixed
```
